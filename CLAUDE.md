## Architecture

EnsembleOT is a Python package that bundles multiple runs of "randomized clustering + cluster-level OT + implicit sample-level lifting". **As a rule, the dense `(n_x, n_y)` transport matrix `T` is never built** — this is a design invariant.

### Data flow (one run)

`run_ensemble_sinkhorn` / `run_ensemble_gw` → `clustering.py` clusters X and Y independently (k-means etc., shifting random_state per run) → `T_cluster` is solved with POT from the cluster-level cost matrix (`sinkhorn.py` / `gw.py`) → the result is returned as an `ImplicitTransportOperator` (`operator.py`) holding `labels_x, labels_y, cluster_mass_x, cluster_mass_y, T_cluster, meta`.

`ImplicitTransportOperator.apply_to_features(F_y)` computes `T @ F_y` using only `T_cluster` and the cluster memberships. The core of the implicit lifting lives in `lifting.py`. An API that expands `T` directly is intentionally not provided.

### Aggregation (`aggregate.py`)

Operators from multiple runs are bundled with `MeanTransportOperator` / `WeightedMeanTransportOperator`. `consensus_edges` / `weighted_consensus_edges` stream over source indices in chunks of `block_size` and never build the `(R, n_x, n_y)` stack or the `(n_x, n_y)` full mean matrix (see README). Do not break this memory property when adding new aggregation routines.

### Run weights (`weights.py`, `convenience.py`)

Based on each `op.meta["metrics"]` (generated by `metrics.py`), `compute_run_weights(policy=..., key="metrics.marginal_error_row")` produces non-negative run weights that sum to 1. `key` is a dot-separated path that traverses `op.meta`. `make_metric_weighted_mean_operator` / `metric_weighted_consensus_edges` in `convenience.py` are shortcuts that combine "compute weights → weighted aggregation" into one call.

### Persistence (`io.py`, `storage.py`)

`save_operators` / `load_operators` bundle only the compact representation of the operators into a single `.npz`. `MeanTransportOperator` also saves its constituent operators and is rebuilt at load time (`save_mean_operator` / `load_mean_operator`). When bumping `FORMAT_VERSION`, keep the `StorageFormatError` path intact. `TrialResult` / `EnsembleResult` in `storage.py` are lightweight in-memory containers.

### Public API boundaries

- The Sinkhorn family (`run_ensemble_sinkhorn`) and the GW family (`run_ensemble_gw`) are **separate entry points**. Do not merge them into a single function.
- The `run_ensemble_gw` side has been filled in incrementally — check the actual implementation in `src/ensembleot/gw.py` before touching it.
- The source of truth for public symbols is `__all__` in `ensembleot/__init__.py`.
